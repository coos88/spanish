# Spanish cheat sheet (for English speakers)

This is the one-page reference. The step-by-step lessons with drills are in [chapters/](chapters/1/README.md) and the app's **Learn** tab.
Default is **Spain** Spanish. Latin American differences are marked *LatAm*.
Hear everything in the [app](https://coos88.github.io/spanish/).

## Pronunciation
Spanish is spelled almost exactly as it sounds. Learn the rules once, then you can read any word aloud.

| Letter | Sound | Example |
|---|---|---|
| a e i o u | always the same, short and pure: *ah, eh, ee, oh, oo* | **a**mi**g**o |
| h | silent | **h**ola = *ola* |
| j, g (before e/i) | rough *h*, like Scottish *loch* | **j**amón, **g**ente |
| g (before a/o/u) | hard *g* | **g**ato |
| gu (before e/i) | hard *g*, u silent | **gu**erra |
| c (before e/i) | Spain: *th* as in *thin*. LatAm: *s* | **c**ena, gra**c**ias |
| c (elsewhere), qu | *k* | **c**asa, **qu**eso |
| z | Spain: *th*. LatAm: *s* | **z**umo |
| ll | Spain: like *y* in *yes* (some regions *ly*) | **ll**ave |
| ñ | *ny* as in *canyon* | espa**ñ**ol |
| rr, r at word start | rolled | pe**rr**o, **r**ojo |
| r (elsewhere) | single tap, like *t* in American "wa**t**er" | pa**r**a |
| v | same as *b*, soft | **v**ino = *bino* |
| b, d, g between vowels | very soft, barely touched | to**d**o |
| ¿ ¡ | opening question / exclamation mark | ¿Cómo estás? |

### Stress (where to put the emphasis)
1. Word ends in a vowel, **n** or **s**: stress the second-to-last syllable. *ha-**bla**, ha-**blan**, **ca**-sa*
2. Word ends in any other consonant: stress the last syllable. *ha-**blar**, ciu-**dad***
3. Exceptions carry an accent mark (**á é í ó ú**) over the stressed vowel. *can-**ción**, **mé**-di-co*
4. The accent mark also separates look-alikes: *si* (if) / *sí* (yes), *el* (the) / *él* (he), *tu* (your) / *tú* (you).

## Nouns, gender, articles
Every noun is masculine or feminine. No neutral.

| | singular | plural |
|---|---|---|
| the (m) | **el** libro | **los** libros |
| the (f) | **la** casa | **las** casas |
| a (m) | **un** libro | **unos** libros (some) |
| a (f) | **una** casa | **unas** casas (some) |

- Ends in **-o** → usually masculine. Ends in **-a** → usually feminine. Exceptions: *el día, el mapa, la mano*.
- Ends in **-ción, -sión, -dad, -tud** → feminine. Ends in **-or, -aje** → masculine.
- Feminine nouns starting with a stressed *a* take *el* in the singular (sound): *el agua* (still feminine: *el agua fría*), *las aguas*.
- Plural: vowel → add **-s** (*casa → casas*). Consonant → add **-es** (*ciudad → ciudades*). **-z → -ces** (*lápiz → lápices*).
- People: *el amigo / la amiga*, *el profesor / la profesora*. Many job nouns ending in **-e** keep the form: *el/la estudiante*.

## Adjectives
Adjectives **agree** with the noun in gender and number, and usually come **after** it.

| | |
|---|---|
| el coche rojo | the red car |
| la casa roja | the red house |
| los coches rojos | the red cars |
| una mujer inteligente | -e / -l / -r endings often don't change by gender |
| un buen amigo, una buena amiga | *bueno, malo, primero, grande* shorten before a noun: *buen, mal, primer, gran* |

## Subject pronouns
| | singular | plural |
|---|---|---|
| 1st | yo | nosotros / nosotras |
| 2nd informal | tú | vosotros / vosotras (*Spain only*; LatAm uses *ustedes*) |
| 2nd formal | usted (Ud.) | ustedes (Uds.) |
| 3rd | él / ella | ellos / ellas |

- **Drop the pronoun**: the verb ending already says who. *Hablo español*, not *Yo hablo español* (use *yo* only for emphasis).
- **tú vs usted**: *tú* with friends, family, peers, kids. *usted* with strangers, older people, formal situations. In Spain most people use *tú* quickly. When unsure, start with *usted*.
- *usted* uses the **3rd person singular** verb: *¿Cómo está usted?*

## Present tense: regular verbs
Drop **-ar / -er / -ir**, add the endings.

| | hablar (-ar) | comer (-er) | vivir (-ir) |
|---|---|---|---|
| yo | habl**o** | com**o** | viv**o** |
| tú | habl**as** | com**es** | viv**es** |
| él/ella/usted | habl**a** | com**e** | viv**e** |
| nosotros | habl**amos** | com**emos** | viv**imos** |
| vosotros | habl**áis** | com**éis** | viv**ís** |
| ellos/ustedes | habl**an** | com**en** | viv**en** |

## The big irregulars
| | ser | estar | tener | ir | hacer |
|---|---|---|---|---|---|
| yo | soy | estoy | tengo | voy | hago |
| tú | eres | estás | tienes | vas | haces |
| él/ella/Ud. | es | está | tiene | va | hace |
| nosotros | somos | estamos | tenemos | vamos | hacemos |
| vosotros | sois | estáis | tenéis | vais | hacéis |
| ellos/Uds. | son | están | tienen | van | hacen |

### Stem-changing verbs ("boot verbs")
The stem vowel changes in **yo, tú, él, ellos** but not in **nosotros, vosotros**.

| e → ie | o → ue |
|---|---|
| **qu**erer: quiero, quieres, quiere, queremos, queréis, quieren | **po**der: puedo, puedes, puede, podemos, podéis, pueden |
| pensar, empezar, preferir, tener, venir | dormir, volver, encontrar, costar |

### Irregular only in "yo"
hacer → hago, poner → pongo, salir → salgo, traer → traigo, saber → sé, ver → veo, dar → doy, conocer → conozco.

## ser vs estar (both "to be")
| **ser**: what something *is* | **estar**: how/where something *is* |
|---|---|
| identity: *Soy Coos.* | location: *Estoy en casa.* |
| origin: *Soy de los Países Bajos.* | temporary state/mood: *Estoy cansado.* |
| profession: *Es médico.* | ongoing action: *Estoy comiendo.* |
| characteristics: *Es alto.* | result of change: *La puerta está abierta.* |
| time & date: *Son las tres. Es lunes.* | |
| material, possession: *Es de madera. Es mío.* | |

Memory aid: **DOCTOR** (Description, Occupation, Characteristic, Time, Origin, Relationship) = *ser*. **PLACE** (Position, Location, Action, Condition, Emotion) = *estar*.
Some adjectives change meaning: *ser aburrido* (to be boring) / *estar aburrido* (to be bored). *ser listo* (clever) / *estar listo* (ready).

## tener (to have) is used for many "to be" things in English
*Tengo 30 años* (I am 30). *Tengo hambre / sed / frío / calor / sueño / miedo / razón / prisa*.
*tener que + infinitive* = must. *Tengo que irme.* (I have to go.)

## hay (there is / there are)
One form for singular and plural: *Hay un banco cerca. Hay dos cafés.* Question: *¿Hay wifi?* Negative: *No hay problema.*

## Negation
Put **no** before the verb. Double negatives are **correct**: *No tengo nada. No hablo con nadie. No veo a nadie nunca.*

## Questions
| | | |
|---|---|---|
| ¿qué? | what | ¿Qué quieres? |
| ¿quién? | who | ¿Quién es? |
| ¿dónde? | where | ¿Dónde está el baño? |
| ¿cuándo? | when | ¿Cuándo llegas? |
| ¿cómo? | how | ¿Cómo te llamas? |
| ¿por qué? / porque | why / because | ¿Por qué estudias español? Porque me gusta. |
| ¿cuánto/a/os/as? | how much/many | ¿Cuánto cuesta? |
| ¿cuál? | which | ¿Cuál prefieres? |

Question words **always carry an accent**. Yes/no questions: just raise your voice: *¿Hablas español?* Add ¿ at the start.

## Numbers
0 cero · 1 uno · 2 dos · 3 tres · 4 cuatro · 5 cinco · 6 seis · 7 siete · 8 ocho · 9 nueve · 10 diez
11 once · 12 doce · 13 trece · 14 catorce · 15 quince · 16 dieciséis · 17 diecisiete · 18 dieciocho · 19 diecinueve
20 veinte · 21 veintiuno · 22 veintidós · 30 treinta · 31 treinta y uno · 40 cuarenta · 50 cincuenta · 60 sesenta · 70 setenta · 80 ochenta · 90 noventa
100 cien (*ciento* before more: *ciento uno*) · 200 doscientos · 500 quinientos · 1000 mil

- *uno* becomes *un* before a masculine noun: *un euro*, *veintiún años*. Feminine: *una*.
- 31 to 99: tens + **y** + unit, written as separate words.

## Time and dates
- *¿Qué hora es?* → *Es la una.* / *Son las dos / las tres y media / las cuatro menos cuarto.*
- *y cuarto* (quarter past), *y media* (half past), *menos cuarto* (quarter to).
- Days (not capitalized): lunes, martes, miércoles, jueves, viernes, sábado, domingo. *El lunes* = on Monday. *Los lunes* = on Mondays.
- Months (not capitalized): enero, febrero, marzo, abril, mayo, junio, julio, agosto, septiembre, octubre, noviembre, diciembre.
- Date: *Es el once de octubre.* (day first, then month.)

## gustar (to like)
Works backwards: the thing liked is the subject. Literally "X is pleasing to me".

| | |
|---|---|
| Me gusta el café. | I like coffee. |
| Me gustan los gatos. | I like cats. (plural thing → *gustan*) |
| Te gusta... / Le gusta... | you like / he, she, you (formal) like |
| Nos gusta... / Os gusta... / Les gusta... | we / you all / they like |
| Me gusta bailar. | I like dancing. (verb → always *gusta*) |
| No me gusta. | I don't like it. |
| ¿Te gusta? / ¿Le gusta? | Do you like it? (informal / formal) |

Similar: *me encanta* (I love), *me interesa*, *me duele* (it hurts me).

## Talking about the future: ir a + infinitive
*Voy a comer.* (I'm going to eat.) *Vamos a ver.* (We'll see / let's see.) *Mañana voy a trabajar.*
*Vamos a + infinitive* also means "let's...": *¡Vamos a comer!*

## Right now: estar + gerund
-ar → **-ando**, -er/-ir → **-iendo**. *Estoy hablando. Estamos comiendo. Está viviendo en Madrid.*
Use it for what is happening *at this moment*. For habits and general facts, use the simple present.

## Reflexive verbs
The action reflects back on the subject. Pronoun before the verb: **me, te, se, nos, os, se**.
*Me llamo Coos.* (I call myself Coos.) *Me levanto a las siete.* *Se ducha por la mañana.*
Infinitive: *llamarse, levantarse, ducharse, sentarse, acostarse*.

## Object pronouns (the basics)
| direct (it, him, her, them) | |
|---|---|
| lo / la | *Lo tengo.* (I have it.) *La veo.* (I see her/it.) |
| los / las | *Los compro.* (I buy them.) |

Placed **before** the conjugated verb, or attached to an infinitive: *Lo quiero comprar* = *Quiero comprarlo.*
Indirect (to/for me, you...): **me, te, le, nos, os, les**. *¿Me das el agua?* *Le doy el libro.*

## Polite requests
| | |
|---|---|
| Quisiera un café, por favor. | I would like a coffee. (very polite) |
| Quiero un café. | I want a coffee. (fine in a bar, blunt elsewhere) |
| ¿Me pone un café? | Could I have a coffee? (Spain, at a bar) |
| ¿Puede ayudarme? | Can you help me? (formal) |
| Perdone... / Disculpe... | Excuse me... (to get attention) |
| ¿Me puede decir...? | Can you tell me...? |

## What's next?
You now have the **present tense**, the foundation of everything. The next steps, in order:
1. **Pretérito** (simple past): *hablé, comí, viví*, plus the irregulars *fui, hice, tuve*.
2. **Imperfecto** (habitual/descriptive past): *hablaba, comía*.
3. **Pretérito perfecto** (present perfect): *he hablado, he comido*.
4. **Future** (*hablaré*) and **conditional** (*hablaría*).
5. **Subjunctive**. That's the next big wall, but you can survive a long time without it.
