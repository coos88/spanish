Each answer key is hidden in a `<details>` block under the exercises.

## Rules
- Write full sentences with accents and ¿ ¡. Check them against the key, then **say them out loud**.
- Anything you got wrong: add it to a list and redo it tomorrow.
- Done = you can do the exercise again without looking at the cheat sheet.
- Then use the app's quiz and verb drill to make it stick.
