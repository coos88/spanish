# Phrases: survival Spanish

Whole phrases beat single words. Say them out loud; hear them in the [app](https://coos88.github.io/spanish/).

Generated from `data/phrases.json` by `node tools/gen-docs.js`. Don't edit by hand.

## Introductions

| Spanish | English |
|---|---|

| Me llamo Coos. | My name is Coos. |
| ¿Cómo está usted? | How are you? (formal) |
| ¿Cómo estás? | How are you? (informal) |
| Estoy bien, gracias. ¿Y tú? | I'm fine, thanks. And you? |
| ¿De dónde eres? | Where are you from? (informal) |
| Soy de los Países Bajos. | I'm from the Netherlands. |

## Getting by

| Spanish | English |
|---|---|
| No entiendo. | I don't understand. |
| Más despacio, por favor. | More slowly, please. |
| ¿Puede repetir, por favor? | Can you repeat, please? (formal) |
| ¿Habla inglés? | Do you speak English? (formal) |
| ¿Cómo se dice esto en español? | How do you say this in Spanish? |
| ¿Qué significa esto? | What does this mean? |
| No sé. | I don't know. |
| ¿Qué hora es? | What time is it? |
| ¿Hay wifi aquí? | Is there wifi here? |
| ¿Dónde está el baño? | Where is the bathroom? |

## Eating & drinking

| Spanish | English |
|---|---|
| Una mesa para dos, por favor. | A table for two, please. |
| Quisiera un café con leche. | I would like a coffee with milk. |
| ¿Me pone una cerveza, por favor? | Could I have a beer, please? (Spain, at a bar) |
| ¿Qué recomienda? | What do you recommend? (formal) |
| Soy vegetariano. | I'm vegetarian. (f: vegetariana) |
| Sin carne, por favor. | Without meat, please. |
| Está muy rico. | It's really tasty. (¡Está delicioso! is more formal) |
| La cuenta, por favor. | The bill, please. |
| Tengo sed. | I'm thirsty. |
| Tengo hambre. | I'm hungry. |
